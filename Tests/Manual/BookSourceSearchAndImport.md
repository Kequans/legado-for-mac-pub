# 书源搜索与书籍导入手工验证

## 搜索停止

1. 导入多个启用的书源，搜索一个能在至少一个书源中找到的书名。
2. 确认搜索结果出现后仍会继续收集其它候选书源，直到用户选择或关闭搜索。
3. 点击某个搜索结果，确认搜索任务被取消，之后不再启动新的书源请求；确认结果包含书名、作者、详情页地址和书源信息。

## 书籍信息与章节

1. 从搜索结果加入书架，确认书架中书名和作者不为空。
2. 打开书籍，确认阅读器标题不为空，并能加载目录和第一章正文。
3. 在详情页规则无法取得书名的书源上重复验证，确认搜索结果中的书名会回填到书籍记录。
4. 打开换源页面，确认会继续收集同名书源；点击“换源”后搜索任务被取消，其余请求停止。

## 规则回归

- 使用包含 `@put:{...}` 和 `@get:{...}` 的书源，确认书名、作者和简介字段可以从 meta 标签读取。
- 使用详情页只有 `<title>` 或 `<h1>` 的书源，确认书名回退解析有效。
